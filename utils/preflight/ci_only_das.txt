# CI-only das surface: in-repo files no default local build compiles, swept by
# the preflight `ci-das` gate with `daslang -compile-only`.
# Format: <glob> | <native modules whose absence means SKIP, comma-separated> | <rebuild hint>
# A compile failure whose missing prerequisite is NOT in the allow-skip list is a FAIL.
#
# Prefer files whose requires resolve entirely in-repo. Surfaces that pull
# external daspkg packages (examples/games/sequence -> das-cards) belong to the
# `sequence` gate instead — its ci_smoke_test script installs the deps fresh,
# while a bare -compile-only would read whatever stale gitignored install is
# lying around and report phantom errors.
# Exception: a disable-able native module is fine IF named in the allow-skip
# column — its absence then downgrades to SKIP locally and it still compiles in
# CI (see the dasOpenGL/opengl entry's `imgui`, off in DAS_GLFW_DISABLED /
# DAS_IMGUI_DISABLED builds). Don't "fix" that by removing it.
modules/dasOpenGL/opengl/*.das | glfw, opengl, imgui | rebuild with -DDAS_GLFW_DISABLED=OFF (dasImgui builds in-tree by default)
modules/dasOpenGL/glsl/*.das | glfw, opengl | rebuild with -DDAS_GLFW_DISABLED=OFF
# imgui-consuming tools: no default local build compiles these unless
# dasGlfw/dasImgui are on; CI sweeps them per-PR via the extended_checks
# "Compile CI-only das surface" step (this same list). The dasImgui examples
# themselves are deliberately NOT here — the nightly playwright suite
# compiles AND runs them as spawned daslang-live apps, and a per-PR compile
# of all ~200 would cost minutes per lane for signal the nightly already has.
utils/jobque-timeline/*.das | imgui, dashv | rebuild with -DDAS_GLFW_DISABLED=OFF (dasImgui builds in-tree by default)
utils/dasHerd/watcher/rich_client.das | imgui, dashv | rebuild with -DDAS_GLFW_DISABLED=OFF (the dasHerd UI graph root)
# GL path tracers (OpenGL<->Vulkan harmonization compat, HARMONIZATION_PLAN.md section 8.1): GLFW-gated
# and need a GPU to run, so compile-only. The CPU rail (toy_path_tracer.das) is a run gate via ADD_EXAMPLE_RUN.
examples/pathTracer/*opengl*.das | glfw, opengl | rebuild with -DDAS_GLFW_DISABLED=OFF

The sidecar exchange is closed.

A sidecar is dasLLAMA's per-box tune manifest: which JIT kernel variant won in each of ~40 families, the tuned runtime scalars, and the provenance to prove where it came from. dasLLAMA now ships those winners as class profiles - one per CPU feature class, checked into the engine - and a box its class profile covers is tuned by its first compile: no download, no race, no restart. A box no profile covers tunes itself locally at first start. The exchange client is off by default (exchange_accept = off); this page remains as the browser of what the exchange collected.

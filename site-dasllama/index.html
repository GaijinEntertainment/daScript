Local inference, written in daslang.

dasLLAMA is an LLM + speech-to-text inference engine written entirely in daslang and JIT-compiled. It loads stock GGUF files and runs them on cpu, metal, or vulkan. Kernels are auto-tuned per box; the winning variants are saved as a sidecar you can pick up instead of tuning yourself. This is the working site: news, every measurement, every sidecar.

§ 02how to get it

Three lines, no build step.

dasLLAMA ships inside the daslang SDK. Point the JIT at a script that requires it, or run dasllama-server for the turnkey path — it asks about sidecars at startup.

01daslang SDK ↗ — pre-built binaries for macOS, Linux, Windows
02drop a GGUF next to the script; nothing to convert
03server mode picks up a matching sidecar, or tunes for your box
run.dasjit
// LLM inference in daslang — JIT, no C++ require dasllama/dasllama [export] def main() { var m <- load_model("model.gguf", QuantMode.q4k) var s = create_session(m) generate(m, s, encode(m, "Summarize:"), SamplingParams(), 128l) $(_id, p) { print(p); return true } }
$ daslang -jit run.das
sidecar: verified · darwin|arm64|MacBookPro18,2 · 40/40 kernels
✓ prefill 217.7 tok/s · decode 34.5 tok/s
$ dasllama-server --model model.gguf --port 8080

[dasllama-v0.6.6](https://github.com/GaijinEntertainment/daScript/releases/tag/dasllama-v0.6.6) carries
the release-17 re-mint: every `[tune]` kernel ships as one clone per CPU class from the release-17
class profiles - arm-neon, arm-i8mm, arm-sve, x86-avx2, x86-vnni512 and x86-amx - and the
[ladder](/ladder.html) measures it on the M5 Max, Granite Rapids, EPYC 9R14, Graviton4 and an
RTX PRO 4500. The wheels are on pypi.org now, so `pip install dasllama` needs no index; brew,
scoop, the `.deb` and the `.rpm` install the same four programs, and the [get it](/#get-it)
section names every form.

# Version Update Skill

How to update the daslang version number across the codebase.

## Canonical version sources (MUST update)

| File | What to change | Example |
|---|---|---|
| `include/daScript/misc/platform.h` | `DAS_VERSION_MAJOR`, `DAS_VERSION_MINOR`, `DAS_VERSION_PATCH` macros | `#define DAS_VERSION_PATCH 1` |
| `CMakeLists.txt` (line 2) | `project (DAS VERSION X.Y.Z)` | `project (DAS VERSION 0.6.1)` |
| `doc/source/conf.py` | `version` and `release` — both carry the full X.Y.Z (de-facto since 0.6.3) | `version = u'0.6.4'`, `release = u'0.6.4'` |

## Documentation (MUST update)

| File | What to change |
|---|---|
| `doc/source/reference/index.rst` | Title: `Daslang X.Y.Z Reference Manual` |
| `doc/source/stdlib/index.rst` | Title: `Daslang Standard Library X.Y.Z` |
| `doc/source/stdlib/handmade/function-builtin-get_das_version-0x47c28931e7e7291e.rst` | Example version string in `get_das_version()`'s description (`generated/builtin.rst` is gitignored and regenerated by das2rst — editing it is futile) |
| `install/README.md` | `- **Version:** X.Y.Z` line |
| Live `site/*.html` pages and `site/blog/template.html` | `forge-nav__version` chip |
| `site/README.md` | Documented navigation-chip version |

## Derived (auto-computed, no manual change needed)

These are computed from the macros in `platform.h` — no manual update required:

- `DAS_VERSION` composite macro: `MAJOR*10000 + MINOR*100 + PATCH`
- `DAS_BUILD_ID`: `DAS_VERSION * 100 + sizeof(void*) [+ 10 if assertions]`
- `get_das_version()` runtime function in `src/builtin/module_builtin_runtime.cpp` — formats from the macros
- CMake `PROJECT_VERSION` — derived from the `project()` call

## Full version (X.Y.Z)

- The RST manual titles and both `conf.py` fields carry the **full** X.Y.Z. Bump all of them on every release.
- Historical release notes and benchmark provenance keep the version they recorded.

3. Edit both `version` and `release` in `doc/source/conf.py`
4. Edit `doc/source/reference/index.rst` title
5. Edit `doc/source/stdlib/index.rst` title
6. Edit the `get_das_version()` example string in `doc/source/stdlib/handmade/function-builtin-get_das_version-0x47c28931e7e7291e.rst`, then regenerate via das2rst
7. Edit `install/README.md` version line
8. Edit the live site navigation chips and their `site/README.md` description; leave historical news and benchmark provenance untouched
9. Build and verify `get_das_version()` returns the new version

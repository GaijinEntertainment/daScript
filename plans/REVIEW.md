# plans Code Review Checklist

**Read `REVIEW_COMMON.md` (repo root) first - its contract binds this checklist.**

**A diff that writes a measured number into a document here - from a dasLLAMA run, from a run
of a reference arm, or copied from a reference arm's own publication - applies
`modules/dasLLAMA/REVIEW_MEASUREMENT.md` too.** A reference arm is any third-party engine or
package a dasLLAMA run is measured against.

**A diff that writes into a document here the name of the third-party engine dasLLAMA measures
itself against - the checkout `modules/dasLLAMA/benchmarks/setup_lcpp_ref.das` pins - or a
description of one of its mechanisms, applies `modules/dasLLAMA/REVIEW_UPSTREAM.md` too.**

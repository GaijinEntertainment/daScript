================================
 zed-daslang --- Zed extension
================================

A Zed extension for daslang. It registers the ``.das`` file type, builds
the tree-sitter grammar from a pinned revision of the daScript
repository, and highlights ``.das`` files with its own copy of the
highlight query. The extension ships as source in ``utils/zed-daslang``.

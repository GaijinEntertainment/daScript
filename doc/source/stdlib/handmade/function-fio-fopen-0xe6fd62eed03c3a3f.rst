Opens the file at ``name`` with the given ``mode`` (e.g. ``"r"``, ``"w"``, ``"rb"``, ``"a+"``) and returns a file handle, or ``null`` if the file cannot be opened. Throws if ``name`` is null or if ``mode`` is not a valid fopen mode string (first char must be ``r``/``w``/``a``; remaining chars limited to ``+``/``b``/``t``/``x``). The block form invokes the block with the handle (``null`` when the file cannot be opened) and closes it after; a panic inside the block still closes the file before it reaches the caller.

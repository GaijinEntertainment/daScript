Sets on ``policies`` the items the project file behind ``access`` returns from its ``project_policies`` function - the ``name=value`` items ``set_policy`` takes, separated by ``;`` or by line - in order, and stops at the first one refused: the items before it stay set. Returns an empty string when the project has no such function or every item was set, and otherwise the reason the refused item gave. A host calls it after its own defaults and before its command-line overrides.

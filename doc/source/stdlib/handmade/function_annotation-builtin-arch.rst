Binds the function to a section of an architecture document: ``[arch(at="<doc>.md#<anchor>")]``, where the path resolves relative to the citing file's folder. Repeat the annotation to cite more than one section. The compiler checks only the shape - exactly one ``at=`` string, a document path and an anchor, both non-empty, separated by ``#``; whether the citation resolves to a real section is checked by the LINT026 rule in the lint runner, which the annotated code does not need to require - the marker itself is metadata only and costs nothing. A structure or class takes the same spelling, unvalidated by the compiler, since a module holds one annotation per name.

Open ``path`` for cache-bypassing positional reads (``FILE_FLAG_NO_BUFFERING`` on Windows, ``O_DIRECT`` on Linux, ``F_NOCACHE`` on macOS), so a cache of blocks read on demand into pinned memory is not doubled in the page cache. ``band_bytes`` sizes the handle's aligned bounce band (0 = the default, 4 MiB), which takes the sectors a span shares with its neighbours and any span whose destination is not sector-aligned. Returns null where the file does not open. One handle per reader thread — a handle is not shared.

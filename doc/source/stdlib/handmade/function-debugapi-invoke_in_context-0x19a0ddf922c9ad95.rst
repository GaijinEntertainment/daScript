Calls a function in another context.  Accepts a `Context` reference and either a function name (string), a `function` pointer, or a `lambda`, plus up to 10 extra arguments.  Target functions must be marked `[export, pinvoke]`.  A name resolves against every function the context simulated, and a name held by more than one of them - an overload, a same-named function in another module - is an error rather than a pick.

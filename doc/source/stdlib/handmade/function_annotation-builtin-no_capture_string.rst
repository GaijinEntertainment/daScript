Declares that the function keeps no string argument past the call, whatever it writes into its other arguments. A function that writes to an argument holding strings is otherwise taken to store the string it was given, and a caller then keeps that string alive. With the annotation a fresh string passed to the function - a string builder, or the result of a ``[temp_string_result]`` call - is freed by the temp-string reclaim pass. ``erase`` on a table carries it: it looks its key up and stores nothing. A function that carries it and does keep a string is read as free of that effect by constant folding and escape analysis too.

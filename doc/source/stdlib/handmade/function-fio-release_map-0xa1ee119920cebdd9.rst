Lets the pages of a mapped range leave the process: ``bytes`` starting at ``base``, rounded inward to whole pages, drop out of the resident set and are read from the file again on the next touch (``madvise(MADV_DONTNEED)`` on Linux, ``msync(MS_INVALIDATE)`` on macOS, ``VirtualUnlock`` on Windows). Use it on an ``fmap``/``fmap_open`` mapping once a range has been consumed, so a pass over a large file holds the range in flight and not the file. Only for read-only file-backed mappings: on anonymous memory the same call discards the contents on Linux, and over a writable shared mapping it can drop changes not yet written back. Returns false when the OS declines, when ``bytes`` is zero or when the range holds no whole page; reads work either way. A null ``base`` with ``bytes`` to release panics.

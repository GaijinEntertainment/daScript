Switches the stream to binary mode, so the bytes written are the bytes sent and the bytes read are the bytes received: no newline translation, no end-of-file character. Only Windows has a text mode, where a stream defaults to writing ``\n`` as ``\r\n``, so a ``\r\n`` becomes ``\r\r\n``; elsewhere this is a no-op. Use it on ``fstdin()`` and ``fstdout()`` when the stream carries a byte-counted protocol such as LSP framing.

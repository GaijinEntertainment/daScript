True when the runtime binary itself was compiled with relaxed float flags (``-ffast-math`` or ``/fp:fast``). Such a build reassociates float arithmetic, contracts multiply-add pairs and flushes denormals, so a vector result and its scalar reference stop matching bit for bit; the JIT inherits the flag unless ``options fast_math`` says otherwise. Detection is by predefined macro, so a host built with only part of the relaxation (``-funsafe-math-optimizations``, ``-freciprocal-math``) still reports false.

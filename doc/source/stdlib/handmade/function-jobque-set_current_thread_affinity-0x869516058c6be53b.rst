Binds the calling thread to logical processor `cpu`. With `hard` true it is a mask on Windows and Linux (the thread never leaves that core); with `hard` false it is a scheduler hint (Windows ideal processor; nothing on Linux). macOS has no pin API: there the call sets the thread's QoS class instead - the top class when `hard`, the user-initiated class otherwise - which is what keeps a thread on the performance cores across blocks. An index outside the platform's range is ignored on the platforms that pin: negative anywhere, 64 or more on Windows (the thread's own processor group, no group switching), `CPU_SETSIZE` or more on Linux.

Compiles ``module_name`` - a ``shared`` module, named by its file - and its prerequisites into the process at the point of the call, or answers the module already there, under ``codeOfPolicies``; a null ``fileAccess`` means the compiling program's own. Issued from a compile - a macro, a simulate macro, an ``[init]`` - and an error from a running script, which has no compile for the modules to join. Calls ``block`` with the module (null on failure) and the compile log. The module is not a dependency of the caller: reach it through its macro context (``find_macro_context``, ``invoke_in_context``).

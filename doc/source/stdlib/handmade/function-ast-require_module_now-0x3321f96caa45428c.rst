Compiles ``module_name`` - a ``shared`` module - and its prerequisites into the process at the point of the call, or answers the module already there, under ``codeOfPolicies``; a null ``fileAccess`` means the default file access. Calls ``block`` with the module (null on failure) and the compile log. The module is not a dependency of the caller: reach it through its macro context (``find_macro_context``, ``invoke_in_context``).

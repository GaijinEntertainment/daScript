Read ``bytes`` at file offset ``off`` into ``dst`` — any pointer, any offset, any size. The handle re-blocks the unaligned head and tail of the span through its band and reads an aligned middle straight into ``dst`` where ``dst`` is sector-aligned, in band-sized pieces otherwise. Returns the bytes read: short where the span runs past the end of the file, 0 for a span starting past it or an empty one, -1 where a read failed.

Performs synchronous verified HTTPS with a response-body limit of 1–16777216 bytes. Empty ca_file selects system trust; otherwise the given CA file establishes trust. Timeout must be 1–120 seconds. Redirects, retries and request proxies are disabled. Returns zero on transport success and then invokes block with a borrowed response, including non-2xx statuses; other results do not invoke block. Truncation, oversized bodies, invalid URLs and TLS verification failure are errors. Copy any needed response data inside block.

Keeps the function's floating-point arithmetic, and that of the block literals written in its body, exact under options fast_math: the LLVM tiers (JIT, LLVM-AOT, -exe) emit it without the reassoc, nsz and contract flags every other function gets. It implies [never_inline], since daslang's own inliner would move the arithmetic into an unmarked caller, and combining it with [inline] is a compile-time error. Use it on a recurrence whose feedback gain is above one, such as an IIR filter tick, where two differently rounded copies of the state diverge. The interpreter is unaffected, and so is C++ AOT, which the host compiler's fast-math flag governs.

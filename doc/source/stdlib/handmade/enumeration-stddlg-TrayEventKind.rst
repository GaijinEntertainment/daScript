What a tray event reports: how the icon or its menu was used.
Left click (or keyboard select) on the icon; the second press of a double click on Windows and macOS follows as double_click.
The second press of a double click, after its click; Windows and macOS only, Linux hosts report two clicks.
Right click (or control-click) on the icon; the context menu opens after the event is queued.
A menu entry was chosen; the event's id is the entry's id from tray_menu_add.
The notification balloon was clicked; Windows only.

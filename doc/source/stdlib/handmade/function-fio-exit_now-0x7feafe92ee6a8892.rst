Ends the process at once with the given exit code: stdout and stderr are flushed, and nothing else runs - no ``atexit`` handler, no module teardown, no leak dump. This is the exit for a thread other than the main one: a plain ``exit`` there tears the runtime down under the main thread while it is still running, and waits on the calling thread itself in the job queue's teardown. On the main thread prefer ``exit``, which shuts down in order and reports a non-zero code with a stack trace.

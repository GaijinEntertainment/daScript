Spawns a subprocess directly via argv, bypassing the shell, in the directory ``cwd`` (empty inherits the caller's) with each ``env`` entry, ``KEY=VALUE``, applied over the inherited environment.  Otherwise it is the ``timeout`` form of ``popen_argv``: the block gets the merged stdout+stderr FILE pointer, and the call returns the exit code, or ``popen_timed_out`` once a positive ``timeout`` passes.  A relative ``args[0]`` that names a path resolves against the caller's directory, not ``cwd``; on POSIX a ``cwd`` the child cannot enter makes it exit 127.

Sets one field of ``policies`` from text: ``name=value``, or a bare ``name`` to turn a bool on - the form ``daslang -policy`` takes. The name is the field's C++ name (``force_inscope_pod``, ``stack``). Returns an empty string when the field was set, and otherwise the reason: the name is no policy, the value does not fit the field's type, or the field cannot be set from text. A refused item leaves ``policies`` as it was.
